# Native Complex T2 Autoencoder

This folder contains a native-complex PyTorch autoencoder for the generated T2 coil images.

The model consumes tensors shaped `(batch, 1, 320, 320)` with dtype `torch.complex64`. It does not split real and imaginary parts into separate channels. The convolution weights, activations, predictions, targets, and latent tensors remain complex tensors. The reconstruction losses are real-valued functions of complex tensors, so PyTorch applies its Wirtinger autograd convention during `loss.backward()`.

## Data

The default config expects files generated by:

```powershell
python reconstruction_T2_samples/generate_t2_samples.py --output-size 320 320 --compressed-coils -1
```

and stored under:

```text
F:\fastmri_prostate\t2_samples\features\training
F:\fastmri_prostate\t2_samples\features\validation
F:\fastmri_prostate\t2_samples\features\test
```

Each `.npy` file must be a native NumPy complex array with shape `(320, 320)` or `(C, 320, 320)`.

## Train

```powershell
python -m src.autoencoder.train --config configs/t2_complex_autoencoder.yaml
```

The training run writes `best_model.pt`, `last_model.pt`, `history.json`, `summary.json`, and reconstruction-error CSV files to the configured output directory.

## Evaluate

```powershell
python -m src.autoencoder.evaluate --checkpoint runs/complex_t2_autoencoder/best_model.pt --split test
```
